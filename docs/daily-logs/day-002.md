## Build Issues Resolved
1. `cb->info` missing → Added `CONFIG_NET_MGMT_EVENT_INFO=y`
2. WiFi driver linker error → Added `&wifi { status = "okay"; }` to DTS overlay
3. Ethernet L2 undefined refs → Added `CONFIG_NET_L2_ETHERNET=y`
4. ext_ram_seg overflow → Reduced SPIRAM heap from 4MB to 3MB (WiFi uses some SPIRAM)
5. Flash at 921600 baud fails → Use 460800 baud with external USB-TTL adapter
6. Serial port locked → Must kill stale monitor processes before flashing

## Key Learnings
- ESP32 WiFi driver in Zephyr uses Ethernet L2 internally — always need `CONFIG_NET_L2_ETHERNET=y`
- WiFi DTS node must be explicitly enabled in overlay: `&wifi { status = "okay"; }`
- Net mgmt event info (IP address in callback) requires `CONFIG_NET_MGMT_EVENT_INFO=y`
- ESP32 can only map 4MB of PSRAM — heap + WiFi SPIRAM allocs must fit within that
- USB-TTL adapters often can't handle 921600 baud — use 460800 for reliable flashing
- Always free the serial port (kill monitor) before attempting `west flash`
