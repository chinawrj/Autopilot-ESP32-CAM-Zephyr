## Release Summary (v1.0.0)
- 16 development days from scratch to first release
- OV2640 camera with 6 resolution levels (QVGA → UXGA)
- Dual-path streaming (MJPEG TCP + WebSocket)
- Web UI with HUD, LED control, resolution selector
- REST API for all device functions
- Zero memory leaks, hardware watchdog, WiFi auto-reconnect
- Built on Zephyr RTOS v4.1.0
