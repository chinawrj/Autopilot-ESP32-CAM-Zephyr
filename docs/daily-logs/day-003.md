## Architecture Decisions

- **Camera driver deferred**: ESP32 (original) has no Zephyr DVP driver; I2S camera mode
  requires custom driver work. Building HTTP/MJPEG infrastructure first with test pattern.
- **Connection model**: 1 listener thread + 1 streaming worker, max 1 concurrent stream client.
  Send timeouts for slow-client protection.
- **Frame source abstraction**: `frame_source_get()` returns current JPEG frame; camera
  backend plugs in later without HTTP layer changes.
- **Test JPEG**: Embedded 160x120 color-bar JPEG in flash/rodata (~2-4 KB).
- **Socket API**: `CONFIG_POSIX_API=y` for POSIX socket names (Zephyr 4.1 removed POSIX_NAMES).
