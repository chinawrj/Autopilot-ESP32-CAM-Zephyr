## Key Decisions
- **Header not .c**: Used private `.h` included once rather than `.c/.h` pair since the HTML arrays are `static const` and only needed by http_server.c. No flash duplication risk.
- **Skipped WS extraction**: WebSocket code is tightly coupled to stream ownership/handoff. Splitting would risk subtle regressions for minimal maintainability gain.
- **Soak test design**: Two-phase approach (sustained + cycles) catches both per-frame leaks and teardown leaks. Baseline comparison after cooldown avoids false positives from transient TCP buffers.
